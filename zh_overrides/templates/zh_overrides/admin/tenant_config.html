① 两种模式与生效规则

  • 通用模式：组织配了 App 凭证 → 全组织工作区共享，工作区凭证即使存在也被忽略。
  • 独立模式：组织无凭证行 → 每个工作区只认自己的凭证；未配置的工作区连接卡片置灰、无法发布，不向任何默认 App 回退。
  • 环境变量完整配置优先级最高；服务器 .env 不含 Meta 凭证，不参与判定。

② 新租户标准流程

  • 1. 本页「新建租户登录账号」（或让用户 Google 登录后再改名）。
  • 2. 展开租户卡片，选模式并保存。
  • 3. 独立模式：「+ 添加工作区」逐行填名称+两对凭据+测试员备注并保存。
  • 4. Meta 后台为每个客户建 Business App、加用例/权限、登记回调、配 Webhook、加 Tester。
  • 5. 把第⑤节的回调/口令发给租户照抄。
  • 6. 租户登录各工作区 Connect 完成 OAuth（用 Tester 账号）。
  • 7. 必要时服务器执行 subscribe_webhooks 补订阅。
  • 8. 发测试帖验收，连接状态列会实时显示。

③ 各字段从哪里取

  • FB App ID/Secret：Meta 应用「应用设置 → 基本」普通应用编号/密钥。
  • IG App ID/Secret：「Instagram API」用例 → API setup with Instagram Login 中的独立编号/密钥（与 FB 不同身份，勿混用）。
  • 备注列：记录 Tester 账号、主页名/Page ID、IG 账号/IG ID，仅运营台账用途。

④ 权限清单（逐字）

  • Facebook（9 项）：business_management、pages_show_list、public_profile（自动）；pages_manage_posts、pages_manage_engagement、pages_read_engagement、pages_read_user_content、pages_manage_metadata、read_insights；另加 Messenger 用例 pages_messaging。
  • Instagram（5 项）：instagram_business_basic、instagram_business_content_publish、instagram_business_manage_comments、instagram_business_manage_messages、instagram_business_manage_insights。

⑤ 固定回调与共享口令（所有租户/App 相同）

  • FB OAuth：https://v.ysec.cn/social-accounts/callback/facebook/
  • IG OAuth：https://v.ysec.cn/social-accounts/callback/instagram_login/
  • FB Webhook：https://v.ysec.cn/webhooks/facebook/ 订阅 feed/mention/messages
  • IG Webhook：https://v.ysec.cn/webhooks/instagram_login/ 订阅 comments/mentions/messages
  • FB 口令：bb_fb_0fa2264954d3c3ec199ef182d1f556339360
  • IG 口令：bb_ig_1fbd5447cf77507708dcfee4971298462c54

⑥ 测试员邀请路径（开发模式）

  • FB：应用角色页添加 FB 用户为测试者/开发者。
  • IG：IG 手机端 → 设置和隐私 → 网站权限 → 应用和网站 → 测试者邀请 → 接受；账号须 Professional（Business/Creator）。

⑦ 前提 / 法律页 / 删除说明

  • FB 需可管理的公共主页；IG 需专业账号；Threads 本矩阵不接入。
  • 隐私政策 /privacy、服务条款 /terms、综合法律页 /legal、数据删除说明 /data-deletion。
  • Meta「业务账户关联登录设置」：取消授权回调留空；数据删除请求网址填 https://v.ysec.cn/data-deletion。

⑧ 开发模式限制与上线

  • 开发模式：仅应用角色/Tester 账号可完成 OAuth 与数据可见。
  • IG 收真实客户（陌生人）私信需该 App 完成公司验证 + instagram_business_manage_messages 高级访问 + 切 Live；每个客户独立 App 需各自审核。
  • FB 为自有主页开发收发消息免应用审核。
  • IG 令牌约 60 天，Worker 健康检查自动刷新。

⑨ 常见错误码

  • 1349168 回调 URI 未加白名单：逐字一致含尾斜杠，IG 填完点保存。
  • 1349249 未接受测试者邀请：账号端测试者邀请页接受。
  • 4476002 Threads 用错 App 身份（本系统不接 Threads）。
  • not subscribed to Page：python manage.py subscribe_webhooks --platform facebook --retry-failed；诊断 diagnose_facebook。

操作说明

模式规则

  • 通用：组织配了 App，全组织工作区共享，工作区凭证被忽略。
  • 独立：每个工作区只认自己的 App；未配即不可连接，不回退默认。

新租户流程

  • 1. 左上 ＋ 建组织（邮箱+密码）。
  • 2. 选模式；独立模式逐工作区填两对凭证。
  • 3. Meta 后台建 App、登记回调、加 Tester。
  • 4. 租户前台 Connect 完成 OAuth。
  • 5. 发测试帖验收，状态自动显示。

字段来源

  • FB App ID/Secret：应用设置 → 基本。
  • IG App ID/Secret：Instagram API → Instagram Login（与 FB 不同身份，切勿混填）。

固定回调 / 口令

  • FB OAuth：https://v.ysec.cn/social-accounts/callback/facebook/
  • IG OAuth：https://v.ysec.cn/social-accounts/callback/instagram_login/
  • FB Webhook：https://v.ysec.cn/webhooks/facebook/
  • IG Webhook：https://v.ysec.cn/webhooks/instagram_login/
  • FB 口令：bb_fb_0fa22…360
  • IG 口令：bb_ig_1fbd…2c54

权限清单

  • FB：business_management、pages_show_list、public_profile、pages_manage_posts、pages_manage_engagement、pages_read_engagement、pages_read_user_content、pages_manage_metadata、read_insights、pages_messaging。
  • IG：instagram_business_basic / content_publish / manage_comments / manage_messages / manage_insights。

开发模式限制

  • IG 收陌生人私信需公司验证 + manage_messages 高级访问 + 切 Live；每个独立 App 各自审核。
  • IG 令牌约 60 天，Worker 自动刷新。

常见错误码

  • 1349168 回调 URI 未加白（含尾斜杠）。
  • 1349249 未接受测试者邀请。
  • not subscribed to Page：subscribe_webhooks --retry-failed。

安全

  • 本页明文显示全部 App Secret，仅超管可访问；所有写操作入操作日志。
